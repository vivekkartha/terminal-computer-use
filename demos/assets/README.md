# Demo assets

## Recommended launch GIF

Record a 15–30s demo:

1. Create a messy fixture folder (or use Desktop with copies).
2. Run:

```bash
python3 skills/computer/scripts/fs-smart-organize.py --dry-run ~/Desktop
python3 skills/computer/scripts/fs-smart-organize.py ~/Desktop
ls ~/Desktop
```

3. Capture with [asciinema](https://asciinema.org/) + `agg`, or [VHS](https://github.com/charmbracelet/vhs).

Place output at:

- `demos/assets/organize-desktop.gif`

Then embed in the root README.
